# GIF-обзоры WB Monitor от BlankTrail для README

Три анимации создаются из настоящих скриншотов `docs/img/panel-*.png`.
Это последовательности экранов с пояснениями, а не записи живого сеанса.
Скрипт не меняет содержимое скриншотов и не подменяет значения товаров.

Для пересборки нужен Python 3 и Pillow:

```bash
python -m pip install Pillow
python docs/media/build_readme_gifs.py
```

Только один обзор:

```bash
python docs/media/build_readme_gifs.py --tour wb-monitor-quickstart
```

Шрифт — Segoe UI на Windows либо DejaVu Sans на Linux с поддержкой кириллицы.
Результат: GIF 1280 × 964, общий набор цветов, бесконечное повторение,
4,8 секунды на экран и полоса времени. Оптимизация хранит различия между кадрами.

При обновлении интерфейса сначала замените исходные скриншоты, затем пересоберите
анимации и проверьте подписи. Проверьте, что на снимках нет открытых ключей,
токенов и паролей. Скриншоты могут не отражать все вкладки текущей версии.
